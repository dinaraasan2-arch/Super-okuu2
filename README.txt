СУПЕР ОҚУ — Android Studio source project (prototype v1).
Open this folder in Android Studio; sync Gradle and select Build > Build APK(s).
APK is NOT included. Requires Android SDK 35 and Android Gradle Plugin 8.7.3.
The learning screens work offline. Voice uses Android WebView speechSynthesis and may not work on some devices; production version should use native Android TextToSpeech with installed Kazakh voice or bundled licensed recordings.
This is an initial working prototype, not a production release.
